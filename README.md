# My Photography Site

A simple personal photography portfolio website built with HTML, CSS, and JavaScript.

The site acts as a digital business card where visitors can:
- View selected photography work
- Access contact information and social media links
- Learn About Me

---

## Technologies Used

- HTML
- CSS
- JavaScript
- Git / GitHub
- GitHub Pages 

---

## Project Structure

my-photography-site
├── index.html
├── style.css
├── script.js
├── README.md
└── images/

- `index.html` — main webpage structure  
- `style.css` — styling and layout rules  
- `script.js` — JavaScript interactions  
- `images/` —  icons and gallary Photos
